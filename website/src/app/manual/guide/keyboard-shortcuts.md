Every keyboard shortcut in the editor. Press **?** in Cathode to see the same list in **Settings ▸ Keyboard shortcuts**.

On Windows and Linux, read **⌘** as **Ctrl** and **⌥** as **Alt**. Shortcuts do nothing while you are typing in a text field. The grid commands work on the Editor page, on the selected cell; the others work on every page.

## Presets

| Shortcut | Action                                                              |
| -------- | ------------------------------------------------------------------- |
| P        | Open the preset picker (search by name, or type a bank slot number) |
| ⌘PgUp    | Previous preset                                                     |
| ⌘PgDn    | Next preset                                                         |
| ⇧⌘PgUp   | Previous setlist song (of the setlist being played)                 |
| ⇧⌘PgDn   | Next setlist song                                                   |
| F5       | Reload the preset (the saved version, as a fresh load)              |
| ⌘S       | Save                                                                |
| ⇧⌘S      | Save as…                                                            |
| ⌘L       | Preset Leveling                                                     |

## Scenes

| Shortcut | Action             |
| -------- | ------------------ |
| ⌘1 to ⌘8 | Scene 1 to Scene 8 |

## Channels

| Shortcut   | Action                                     |
| ---------- | ------------------------------------------ |
| A, B, C, D | Channel A, B, C or D on the selected block |
| X          | Next channel on the selected block         |
| ⌘I         | Reset the channel                          |

## Blocks

| Shortcut | Action                              |
| -------- | ----------------------------------- |
| Space    | Bypass or engage the selected block |
| ⇧Space   | Engage in all scenes                |
| ⇧⌘Space  | Bypass in all scenes                |
| G        | Make the block global               |
| ⌘B       | Save the block to the Library       |
| F1       | Block Info on or off                |
| Hold ⌥   | Block Info while held               |

## Grid

| Shortcut    | Action                                                       |
| ----------- | ------------------------------------------------------------ |
| ← → ↑ ↓     | Move the selection from cell to cell (with the grid focused) |
| ↵           | Add a block on the selected empty cell or shunt              |
| Q           | Add a block, or replace the selected one                     |
| ⌘X          | Cut the block                                                |
| ⌘C          | Copy the block                                               |
| ⌘V          | Paste (onto a block of the same type: its settings)          |
| ⌘D          | Disconnect all cables of the block                           |
| ⌘U          | Insert a shunt                                               |
| Delete or ⌫ | Remove the block, or the selected cable                      |

## Edit

| ⇧⌘Z or ⌘Y | Redo   |

## With the mouse

| Action               | Where                           | What it does                                                                        |
| -------------------- | ------------------------------- | ----------------------------------------------------------------------------------- |
| Drag up or down      | A knob                          | Turns it. Hold ⇧ for fine steps. (In **Circular** knob mode, drag around the knob.) |
| Scroll               | A knob                          | Turns it, unless the mouse wheel is turned off in Preferences. ⇧ for fine steps.    |
| Double-click         | A knob or its value             | Type a value.                                                                       |
| ⌥-click              | A knob                          | Back to its default.                                                                |
| Right-click          | A knob, switch or choice        | Modifiers, MIDI learn, Perform pages, Set in other presets.                         |
| Double-click         | An empty cell or a shunt        | Add a block.                                                                        |
| Right-click          | A cell                          | The cell's menu.                                                                    |
| Drag                 | A block                         | Move it to an empty cell or shunt, or swap it with another block.                   |
| ⌥-drag               | A block                         | Copy it to an empty cell or shunt.                                                  |
| ⌘-drag               | A block onto another            | Replace the other block.                                                            |
| Drag from the outlet | The dot on a block's right edge | Draw a cable.                                                                       |
| Click                | A cable                         | Select it (then Delete removes it).                                                 |

## In a focused knob

| Key                | What it does                       |
| ------------------ | ---------------------------------- |
| ↑ or →             | Up by 1 % of the travel (⇧: 0.1 %) |
| ↓ or ←             | Down by 1 % (⇧: 0.1 %)             |
| Page Up, Page Down | Up or down by 10 %                 |
| Home, End          | To the minimum or maximum          |
| ↵                  | Type a value                       |

## In the block picker and the preset picker

| Key        | What it does                                                            |
| ---------- | ----------------------------------------------------------------------- |
| Type       | Filter the list                                                         |
| Arrow keys | Move through the list (the block picker moves across its grid of tiles) |
| ↵          | Add the highlighted block, or load the highlighted preset               |
| Esc        | Close                                                                   |

## In the desktop app's menus

The desktop app keeps the system's standard menu shortcuts, such as copy and paste in text fields, ⌘Q to quit (Alt+F4 on Windows), ⌘M to minimise, and ⌘R to reload the window. **⌘,** opens Settings from the menu.
